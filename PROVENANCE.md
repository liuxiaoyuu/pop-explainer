# Provenance

- **Authorship.** The instructions, reference files and examples were written for this project by the author with AI assistance (Claude). No text is copied from books, courses or other skill packages.
- **Examples are invented.** Every story, character and number in `skills/pop-explainer/examples/`, `references/examples*.md` and `evals/` is fictional, written to show or test the skill.
- **Named works.** When a user asks for a story set in a named anime, show or game, the skill borrows only the widely known setting and invents a new scene; it never claims the scene happened in the original or quotes it.
- **Learning-research background.** The format follows widely known findings (structure-mapping in analogy, misconception-first instruction, concreteness fading, comparing cases, retrieval practice). They're named in the skill's README as directions to look up, not as specific citations; the skill never cites them to users.

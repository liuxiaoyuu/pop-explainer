# 场景选择对照

先想清楚概念的**结构**（谁影响谁、靠什么筛选、有没有门槛），再从对应的一行挑场景。表里是起点，不是唯一答案：同样结构的场景还有很多，优先选**跟用户生活更近**、或者更新鲜的那个，不要每次都用表里的第一个，也不要照搬 examples.md 和易错清单里已经用过的场景。

| 概念结构 | 场景思路 | 适合的概念 |
|---|---|---|
| 两件事一起变，但背后是第三件事 | 每次主角穿红衣都赢，其实红衣是决赛专用服；冰淇淋和中暑一起多 | 相关≠因果、混杂变量、内生性 |
| 自己挑时机，时机本身就影响结果 | 专挑人多的日子发传单、病重的人住院更久 | 内生性、选择偏差、反向因果 |
| 两种可能会互相抵消 | 光走两条路，都开反而不亮 | 量子叠加、干涉 |
| 只看得见过了筛选的 | 排行榜、出道的练习生、还开着的店、上热搜的博主 | 幸存者偏差、选择偏差 |
| 符合证据的不止一个 | 模糊监控、狼人杀、侦探推理 | 贝叶斯、底数忽略、假阳性 |
| 如果当初没那样会怎样 | 读档重来、平行宇宙、时间线分叉 | 反事实、因果效应、对照组 |
| 攒够才会变 | 能量条攒满放大招、经验值升级、水烧到 100 度 | 阈值、临界点、相变 |
| 越多越没劲 | 吃火锅第 1 盘和第 8 盘肉、连刷第 10 集 | 边际效用递减、边际成本 |
| 只能选一个 | 抽卡预算、RPG 加点、周末只有一天 | 机会成本、约束优化、取舍 |
| 已经花了拿不回 | 买了票的烂电影、氪了金的旧游戏 | 沉没成本 |
| 各自聪明，合起来变笨 | 大逃杀谁先开枪、恋综互选、商场价格战 | 囚徒困境、公地悲剧 |
| 谁单独改都吃亏，所以都不动 | 全班都用一个烂聊天软件、演唱会大家都站着、靠右走 | 纳什均衡、协调问题、路径依赖 |
| 一个极端值拽跑数字 | 老板一人拉高全公司平均工资 | 平均数 vs 中位数、离群值 |
| 越……越…… | 推荐算法越推越窄、明星越红越红、谣言越传越像真的 | 正反馈、马太效应、回音室 |
| 自己调自己 | 梦中梦、俄罗斯套娃、镜子对照 | 递归、自相似 |
| 运气被当成实力 | 教练骂人后队员变好、手气爆棚的下一把 | 均值回归、赌徒谬误、大数定律 |
| 背答案 vs 真会 | 只背真题的学生、只会一个套路的游戏 AI | 过拟合、泛化 |
| 摸黑找最低点 | 大雾下山、蒙眼找房间最低处 | 梯度下降、局部最优 |
| 群体里传开 | 群聊八卦、丧尸片感染链、奶茶店排队效应 | 传播、网络效应、羊群效应 |
| 先见过假的，再认得真的 | 消防演习、看过通缉令的保安 | 疫苗、免疫记忆、训练集 |
| 分组和合起来结论相反 | 两家医院一家专收重症、两个班一个全是尖子生 | 辛普森悖论 |
| 随机推一把 | 抽签分班、天降暴雨、彩票 | 随机对照实验、工具变量、自然实验 |

## 场景挑选的三个检查

1. **关系对得上吗？** 故事里推动结局的因果链，和概念里的因果链是同一条吗？
2. **误解演得出来吗？** 主角能不能自然地相信那个最常见的错误想法并照着做？
3. **一句话复述得了吗？** 读者能不能在读完后，用"就像那个……的故事"一句话说出道理？

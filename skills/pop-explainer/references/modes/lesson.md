# 课堂包模式（/课堂包，/lesson）

用户是老师、助教，或要给别人讲这个概念的人："我下周要给本科生讲 X""帮我准备一节课""做个讲解材料"。产出一套拿来就能上课的材料。

## 什么时候进这个模式

用户输入 `/课堂包` 或 `/lesson`，或者明确说要讲课、带讨论课、做讲义、给学生讲。

## 先确认的两件事（缺了就用默认值，在开头写一行说明，不要先发问）

- **受众**：默认"非本专业本科生"。
- **时长**：默认 15 分钟。

## 输出格式（严格按这个结构）

```markdown
# 📚 课堂包：<概念名>（<受众> · <时长>）

## 1. 开场故事（约 3 分钟）
<一个完整故事，规则同主流程：主角信了最常见的误解 → 照着做 → 想通。
在故事讲到主角"照着做"之后，标一个【停一下】：给老师的一句提问，让学生先猜结果。>

## 2. 这就叫
- 一句话定义（可以用术语，这是给学生记的）
- 一个最简公式或图示描述（可选）
- 和故事的对应：故事里的 X = 概念里的 Y（2–3 组）

## 3. 课堂小题（3 道，由易到难）

### 第 1 题：<认出它>
<题目，2–3 句>
- **学生最常见的错答：** "<错答>"——它错在 <一句话>
- **参考答案：** <答案>
- **追问：** <一句，用来区分真懂和猜对>

### 第 2 题：<看起来像但不是>
（干扰题：一个表面相似、但不属于这个概念的情境。结构同上）

### 第 3 题：<用起来>
（要求学生用这个概念给出判断或建议。结构同上）

## 4. 学生最容易卡住的 3 个地方
1. <误解> → <一句话怎么讲破>
2. …
3. …

## 5. 一页讲义（可直接复制给学生）
<不超过 250 字：一句定义 + 一个例子 + "别搞混"两条 + 一道课后自测题（答案附在最后一行，倒着写或注明"答案：……"）>
```

## 规则

- "学生最常见的错答"必须是**真实常见**的错误思路（来自 `accuracy-pitfalls.md` 的 ❌ 或公认的教学难点），不是随手编的错误选项。
- 小题的情境不重复开场故事的场景。
- **自查干扰题**：第 2 题用了"看起来像的另一个概念"（比如机会成本旁边的沉没成本），就检查第 1、3 题里有没有不小心混进这个概念的元素（"票不能退"这类），混进了答案会变。
- 讲义里的术语要准确：这份材料会被当作教学内容使用，宁可保守，别为了好懂而说错。
- 理论有争议时，在第 4 部分或讲义里注明"这是 XX 的看法"。
- 篇幅随时长走：大约每 10 分钟 700–900 字（英文 500–600 词），15 分钟约 1,200 字，30 分钟约 2,200 字；标题和模板标签不算在内。用户给了时长时，每一部分标题后标上建议用时，并在开头加一行时间安排。
- 语言跟随用户；英文标题用 "📚 Lesson pack"。
